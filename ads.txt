# 이 파일은 "이 사이트의 광고를 판매할 수 있는 업체(판매자)"를 선언합니다.
# 형식: <광고 시스템 도메인>, <퍼블리셔 ID>, <계정 관계>, <인증 기관 ID>
# '#' 뒤는 주석이며 검사에 영향을 주지 않습니다.
#
# [지금 상태]
#   아직 구글 애드센스 승인 전이라 실제 퍼블리셔 ID가 없습니다.
#   그래서 아래 구글 기록은 주석 처리해 두었습니다.
#   → 승인 후 아래 "STEP 2"의 한 줄만 주석에서 빼고 ID를 바꾸면 됩니다.
#
# [STEP 1] 퍼블리셔 ID 확인
#   AdSense 접속 → 계정(Account) → 계정 정보(Account information)
#   → '게시자 ID' 예: ca-pub-1234567890123456
#   ads.txt에는 앞의 "ca-"를 뺀 "pub-1234567890123456"을 씁니다.
#   같은 값은 data/config.js 의 ads.adsenseClient 에도 넣습니다
#   (거기에는 ca-pub- 형식 그대로).
#
# [STEP 2] 아래 한 줄의 맨 앞 '#'을 지우고 ID를 교체
# google.com, pub-0000000000000000, DIRECT, f08c47fec0942fa0
#
# [주의]
#   · AdSense의 'ads.txt 관리(자동)' 기능을 쓰는 경우 Google이 이 파일을
#     자동으로 갱신합니다. 그때는 이 파일을 직접 고치지 않아도 됩니다.
#   · 반영 확인: AdSense → 사이트(Sites) → ads.txt 상태.
#     수정 후 반영까지 수 시간~2주가 걸릴 수 있습니다.
#   · 다른 광고 네트워크를 추가할 때는 그 네트워크가 안내한 한 줄을
#     형식에 맞춰 이어서 적습니다. (애드픽·쿠팡파트너스는 ads.txt 대상이 아닙니다.)
#   · 이 파일에는 BOM·HTML 태그를 넣지 않고, 한 줄에 한 기록만 적습니다.
# =========================================================
